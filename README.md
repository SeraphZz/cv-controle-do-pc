🖐️ Hand Gesture Controller

Projeto de reconhecimento de gestos das mãos em tempo real utilizando Python, OpenCV e MediaPipe.

O sistema utiliza a câmera para identificar os movimentos das mãos e transformá-los em comandos, permitindo controlar diferentes funções do computador através de gestos e comandos de voz.

🛠️ Tecnologias
Python
OpenCV
MediaPipe
PyAutoGUI
SpeechRecognition
SoundDevice
Pyperclip
Tkinter
🚀 Como executar

Instale as bibliotecas necessárias:

pip install opencv-python mediapipe pyautogui pyperclip sounddevice SpeechRecognition

Depois, execute o projeto:

python main.py
🎯 Objetivo

Projeto desenvolvido para explorar Visão Computacional, reconhecimento de gestos e interação humano-computador, utilizando movimentos das mãos e comandos de voz para controlar funções do sistema.

Python • OpenCV • MediaPipe • Computer Vision
